================================================================================
🚀 COMPLETE PRODUCTION DEPLOYMENT GUIDE: TASKFLOW
================================================================================
Stack:
  • Database & Auth & Storage: Supabase (PostgreSQL + RLS + Storage Buckets)
  • Backend : Express.js REST API on Render (Web Service)
  • Frontend: React 18 + Vite SPA on Netlify (with React Dropzone & Theme Switcher)

================================================================================
PART 1: SUPABASE CONFIGURATION (DATABASE, AUTH, STORAGE)
================================================================================

1. SQL Schema & RLS Setup:
   - Go to your Supabase Dashboard: https://supabase.com/dashboard
   - Select your project -> Go to "SQL Editor".
   - Copy the contents of `supabase_schema.sql` (or from the in-app Setup Guide) and click "Run".
   - This creates:
     • `public.users` table with auth sync trigger
     • `public.tasks` table with foreign key `user_id` and attachment columns
     • Table Row Level Security (RLS) policies
     • `task-attachments` Storage Bucket (5MB max limit)
     • Storage Row Level Security (RLS) policies

2. Supabase Auth Email Confirmation (Recommended for Testing):
   - Go to Authentication -> Providers -> Email.
   - Disable "Confirm email" if you want users to log in immediately without email confirmation.

PART 3: DEPLOY FRONTEND TO NETLIFY (React + Vite)
================================================================================

1. Sign in to https://app.netlify.com with GitHub.
2. Click "Add new site" -> "Import an existing project" -> "GitHub".
3. Select your repository: `TaskFlow---SupaBase-Task-Manager`.
4. Configure build settings:
   • Base directory: client        <--- [IMPORTANT]
   • Build command: npm run build
   • Publish directory: dist
   • Functions directory: (leave empty)

5. Environment Variables:
   Under "Site configuration" -> "Environment variables", add:

   KEY                            | VALUE
   -------------------------------|---------------------------------------------------------
   VITE_API_URL                   | https://taskflow-api.onrender.com/api
   VITE_SUPABASE_URL              | https://yzpxutumszxlgxpdajyg.supabase.co
   VITE_SUPABASE_PUBLISHABLE_KEY  | sb_publishable_imKBFK22qpAYrU3s6mNgFQ_8L37XCtW

   *(Note: Ensure '/api' is at the end of VITE_API_URL!)*

6. Click "Deploy Site".
7. Netlify will build and deploy your site in ~1 minute.
8. Your live app URL will look like: `https://your-site-name.netlify.app`
