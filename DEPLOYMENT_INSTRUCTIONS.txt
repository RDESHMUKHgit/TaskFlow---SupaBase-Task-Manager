PART 1: DEPLOY BACKEND TO RENDER (Express.js)
================================================================================

1. Go to https://render.com and sign in with GitHub.
2. On your Render Dashboard, click "New +" -> "Web Service".
3. Connect your GitHub repository.
4. Fill in the following service settings:

   • Name: tasks-manager-api (or any name you prefer)
   • Region: Choose the region closest to you or your Supabase instance
   • Branch: main
   • Root Directory: server        <--- [IMPORTANT: Set this to 'server']
   • Runtime: Node
   • Build Command: npm install
   • Start Command: npm start
   • Instance Type: Free

5. Environment Variables (scroll down to "Environment Variables" section):
   Add the following keys:

   KEY                | VALUE
   -------------------|---------------------------------------------------------
   NODE_ENV           | production
   PORT               | 10000 (Render automatically provides or routes PORT)
   SUPABASE_URL       | https://yzpxutumszxlgxpdajyg.supabase.co
   SUPABASE_KEY       | sb_publishable_imKBFK22qpAYrU3s6mNgFQ_8L37XCtW
   CLIENT_URL         | (Optional: Leave empty for now, or add your Netlify URL)

6. Click "Create Web Service".
7. Wait 2-3 minutes for Render to deploy.
8. Once deployed, copy your Render Service URL:
   Example: https://tasks-manager-api.onrender.com

9. Test the backend in your browser:
   Visit: https://your-render-url.onrender.com/api/health
   You should see: {"status":"online","service":"Tasks Manager API",...}


================================================================================
PART 2: DEPLOY FRONTEND TO NETLIFY (React + Vite)
================================================================================

1. Go to https://app.netlify.com and sign in with GitHub.
2. Click "Add new site" -> "Import an existing project" -> "GitHub".
3. Select your repository.
4. Configure the build settings:

   • Base directory: client        <--- [IMPORTANT: Set this to 'client']
   • Build command: npm run build
   • Publish directory: dist       (or client/dist if base dir is blank)
   • Functions directory: (leave empty)

5. Environment Variables (click "Add environment variable" or under Site Configuration):
   Add:

   KEY           | VALUE
   --------------|---------------------------------------------------------
   VITE_API_URL  | https://your-render-url.onrender.com/api

   *(Note: replace 'your-render-url' with your actual Render URL from Part 1.
    Make sure to include '/api' at the end!)*

6. Click "Deploy Site".
7. Netlify will build and deploy your site in ~1 minute.
8. You will receive a URL like: https://your-app-name.netlify.app


================================================================================
PART 3: SPA ROUTING & CORS (ALREADY CONFIGURED!)
================================================================================

✔ SPA Page Refreshes:
  The file `client/public/_redirects` contains `/*  /index.html  200`.
  This ensures that direct navigation and refreshing on `/tasks`, `/analytics`,
  or `/tasks/:id` will never show a 404 on Netlify.

✔ CORS Support:
  `server/server.js` is pre-configured to accept requests from all `.netlify.app`
  subdomains as well as custom domains.

✨ NOTE ON RENDER FREE TIER SLEEP BEHAVIOR:
Render free tier Web Services spin down after 15 minutes of inactivity.
When you open your Netlify app after a while, the first request may take 30-50
seconds while Render wakes up. All subsequent requests will be instant.
